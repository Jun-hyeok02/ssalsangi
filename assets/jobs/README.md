# 직업 일러스트

직업 선택에 따라 로컬 파일을 자동으로 표시합니다. 2026-10-05 사용자 요청에 따라 메이플스토리 공식 직업 소개의 48개 직업 일러스트를 포함했습니다. 이미지 저작권은 NEXON / Wizet에 있습니다. 출처별 페이지와 이미지 주소는 `sources.json`에 기록했습니다.

`src/jobs.js`의 직업 id와 같은 파일명을 사용하세요. `.jpg` → `.webp` → `.png` 순으로 탐색합니다. 기본 이미지를 교체하려면 해당 직업의 JPG를 교체하세요.

예: nightlord.jpg (나이트로드), shade.jpg (은월), adele.jpg (아델), ren.jpg (렌), lete.jpg (레테).

파일이 없거나 손상되면 default.svg를 표시합니다. 카드와 정산 상단에 동일한 일러스트를 적용합니다. 파일을 추가한 후 사이트를 다시 올리고 새로고침하면 적용됩니다. 사용 권한이 있는 이미지 파일만 넣으세요.
