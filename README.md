# 쌀산기

HTML/CSS/JavaScript로 만든 메이플 보스·사냥 수익 관리 사이트입니다. 기존 `maple-ledger-v1` 저장 데이터와 계산 엔진을 유지합니다. React/TypeScript/Supabase/로그인은 사용하지 않습니다.

## 실행 / 빌드

- `index.html` 파일로 열면 수동 정산이 작동합니다. API 연동은 서버가 있는 배포 주소에서 사용합니다.
- `npm run build` 또는 `pnpm run build`: 배포용 `dist` 생성, 브라우저 및 함수 JavaScript 구문 검증. 새 dependency는 없습니다.
- API 기능을 배포하려면 **프로젝트 소스 + Netlify Functions**를 함께 배포해야 합니다. `dist`만 Netlify Drop에 올리면 기존 정산만 작동하고 API 기능은 작동하지 않습니다.
- 기존 사이트/주소를 그대로 갱신하세요. 파일 주소에서 HTTPS 주소로 이동할 때는 백업 JSON을 가져와야 합니다. 브라우저 간 데이터 자동 동기화는 없습니다.
- 상세 설정: [NEXON 연동 및 배포](docs/NEXON-SETUP.md), 전체 작업 보고: [구현 보고](docs/IMPLEMENTATION-REPORT.md).

## 화면 / 데이터

- 홈: 주간 수익·진행률·남은 결정·모두 완료 시 예상, 캐릭터 카드/검마 현황, 컴팩트 사냥 입력, 획득 요약.
- 카드 클릭: 페이지를 유지하는 정산 팝업. 보스별 완료, 파티 인원, 물욕과 확정 재료, 월간 검마, 캐릭터 정보 및 API 조회.
- 통계: 저장 기록의 월간·주차별 합계와 월간 득템.
- 설정: 메소 환산·조각 가격·물욕 가격·백업/복원.

주간 초기화는 목요일, 검마는 월별입니다. 완료/획득 상태만 기간별로 관리하며 선택 보스와 파티 프리셋은 유지합니다. 주간 보스 월간 귀속은 주 시작일, 사냥은 날짜, 검마는 정산 월 기준입니다.

결정 수익은 `floor(결정 메소 / 파티원) / 1억`, 사냥은 메소와 조각 개수 × 단가, 원화는 합계 × 1억 환산가로 계산합니다. 물욕은 기존 균등 분배, 기록한 재료 수량은 추가 분배하지 않습니다. 남은 예상은 **미완료 결정만** 포함하며 드롭/사냥은 추정하지 않습니다. 모두 완료 시 예상은 현재 실제 수익 + 남은 결정입니다.

`name`/`nickname`/`job`/`level`, 기록과 가격 저장 키는 유지합니다. API 필드는 추가적이며 수동 캐릭터도 계속 사용할 수 있습니다. 최초 갱신 시 가능한 경우 원본 JSON을 `maple-ledger-before-nexon-v1`에 별도 보존합니다. 데이터 읽기 실패 시 기존 값을 덮어쓰지 않습니다.

## 직업 일러스트

기존 `src/jobs.js`, `assets/jobs`의 로컬 일러스트와 fallback을 그대로 사용합니다. API 실제 캐릭터 외형은 공식 `character_image`만 허용하며 이미지 오류 시 직업 일러스트를 유지합니다.

## 검증

모의 NEXON 응답 검증과 기존 엔진 비교/브라우저 회귀 검증을 분리했습니다. 결과와 테스트 파일 위치는 구현 보고를 참고하세요. 테스트용 캐릭터는 별도 Playwright 저장소에만 생성하고 실제 사용자 데이터에 기록하지 않습니다.
